Installation
============

CASM consists of a collection of packages that implement different functionality. If you are learning CASM, `casm-project` is the best place to start. Installing `casm-project` will also install all of the other CASM packages as dependencies.


Install from PyPI
-----------------

.. note::

    CASM is built for macOS x86_64 (Intel), macOS arm64 (Apple Silicon), Linux x86_64, and Linux aarch64.

The latest release of casm-project can be installed with:

    pip install casm-project

Configuration
-------------

.. attention::

    CASM clexulator require a compiler with support for C++17. For GCC, version 10 or later is required.

    If the compiler is made available using a command like ``module load gcc/12.2.1`` make sure to perform that step first.


1. From the CASM installation location
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

On many systems, a single environment variable is needed to configure CASM and it can be determined by inspection of where CASM is installed.

On the command line this can be done using:

.. code-block:: bash

    export CASM_PREFIX=$(python -m libcasm.casmglobal --prefix)

In a Python process this can be done using:

.. code-block:: Python

    import pathlib
    import os
    os.environ["CASM_PREFIX"] = str(pathlib.Path(libcasm.casmglobal.__file__).parent.parent)


2. Using an shell script
^^^^^^^^^^^^^^^^^^^^^^^^

To run a configuration test to determine other environment variables needed to compile and link the clexulator generated by casm-bset (see :func:`~libcasm.clexulator.make_clexulator`) use:

.. code-block:: bash

    python -m casm.bset --autoconfigure --shfile casmenv.sh

If configuration is successful, this will create a file `casmenv.sh` that can be sourced to set the necessary environment variables before using CASM:

.. code-block:: bash

    source ./casmenv.sh


3. In a Python process
^^^^^^^^^^^^^^^^^^^^^^

At the cost of a few seconds each time Python is launched, the configuration test can also be run during a Python process using :func:`~casm.bset.autoconfigure`:

.. code-block:: Python

    import casm.bset
    casm.bset.autoconfigure()

By default, if configuration is successful, this method will set the environment variables found for the current process. If not successful, it will raise an exception.
