CASM Project Directory#

Location:
<project>/
Contents:
Name Description Format
.casm/ CASM project settings and data
basis_sets/ Basis set input, results, and generated code
calculation_settings/ Global calculation settings
enumerations/ Enumerated configurations, events, etc.
fits/ Fitting data
imports/ Structure import data
symmetry/ Symmetry analysis results
systems/ System parameters for Monte Carlo simulations
plot_settings/ Plot settings and saved views

CASM project settings and data#

Location:
<project>/.casm/
Contents:
Name Description Format
prim.json Primitive crystal structure and allowed degrees of freedom (DoF) Prim
chemical_composition_axes.json Chemical composition axes Composition Axes
occupant_composition_axes.json Occupant composition axes Composition Axes
project_settings.json CASM project settings Project Settings
Deprecated contents:
Name Description Format
composition_axes.json Chemical composition axes, for v1 compatibility. Composition Axes

Symmetry analysis results#

Location:
<project>/symmetry/
Contents:
Name Description Format
lattice_point_group.json Lattice point group symmetry operations SymGroup
factor_group.json Crystal factor group symmetry operations SymGroup
crystal_point_group.json Crystal point group symmetry operations SymGroup

Basis set input, results, and generated code#

Location:
<project>/basis_sets/bset.<bset_id>/
Contents:
Name Description Format
bspecs.json Basis function specs BSpecs
basis.json Basis functions Basis
equivalents_info.json Equivalents info for local correlations EquivalentsInfo
cluster_functions.json.gz Cluster functions ClusterFunctions
variables.json.gz Clexulator variables ClexulatorVariables
<projectname>_Clexulator_<bset_id>.cc Clexulator C++ source file Clexulator source
<projectname>_Clexulator_<bset_id>.o Compiled clexulator object file Clexulator object
<projectname>_Clexulator_<bset_id>.so Compiled clexulator shared library Clexulator shared lib

Global calculation settings#

Location:
<project>/calculation_settings/calctype.<calctype_id>/
Contents:
Name Description Format
ref.<ref_id>/chemical_reference.json Chemical reference energies ChemicalReference

Enumeration data#

Location:
<project>/enumerations/enum.<enum_id>/
Contents:
Name Description Format
meta.json Description of the enumeration
scel_set.json Enumerated supercells, as a set SupercellSet
scel_list.json Enumerated supercells, as a list list[SupercellSet]
config_set.json Enumerated configurations, as a set ConfigurationSet
config_list.json Enumerated configurations, as a list list[Configuration]
training_data/ Calculation input and output files
kmc_events/ Enumerated KMC events

Calculation input and output files#

Location:
<project>/enumerations/enum.<enum_id>/training_data/calctype.<calctype_id>/<configname>/
Contents:
Name Description Format
config.json Configuration (occupation and continuous DoF) Configuration
structure.json Ideal crystal structure corresponding to the configuration Structure
structure_with_properties.json Crystal structure with calculated properties StructureWithProperties
POS VASP POSCAR file for the configuration POSCAR
