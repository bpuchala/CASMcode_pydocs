IntegralSiteCoordinate#

Package: libcasm-xtal v3.0a1

class libcasm.xtal.IntegralSiteCoordinate(
self: IntegralSiteCoordinate,
sublattice: SupportsInt | SupportsIndex,
unitcell: Annotated[numpy.typing.ArrayLike, numpy.int64, '[3, 1]'],
)#

Bases: pybind11_object

Specify a site using integer sublattice and unit cell indices

Special Methods

Translate an IntegralSiteCoordinate using operators +, -, +=, -=:

import numpy as np
from libcasm.xtal import IntegralSiteCoordinate

# construct IntegralSiteCoordinate
b = 0
unitcell = np.array([1, 2, 3])
translation = np.array([0, 0, 1])
integral_site_coordinate = IntegralSiteCoordinate(b, unitcell)

# translate via `+=`:
integral_site_coordinate += translation

# translate via `-=`:
integral_site_coordinate -= translation

# copy & translate via `+`:
translated_integral_site_coordinate = integral_site_coordinate + translation

# copy & translate via `-`:
translated_integral_site_coordinate = integral_site_coordinate - translation

Sort IntegralSiteCoordinate by lexicographical order of unit cell indices \((i,j,k)\) then sublattice index b using <, <=, >, >=, and compare using ==, !=:

import numpy as np
from libcasm.xtal import IntegralSiteCoordinate

# construct IntegralSiteCoordinate
b = 0
unitcell = np.array([1, 2, 3])
translation = np.array([0, 0, 1])
A = IntegralSiteCoordinate(0, np.array([1, 2, 3]))
B = IntegralSiteCoordinate(1, np.array([1, 2, 3]))

assert A < B
assert A <= B
assert A <= A
assert B > A
assert B >= A
assert B >= B
assert A == A
assert B == B
assert A != B

Represent IntegralSiteCoordinate as the string "b, i j k", where b is the sublattice index and i j k are the unit cell indices, using str():

import numpy as np
from libcasm.xtal import IntegralSiteCoordinate

# construct IntegralSiteCoordinate
site = IntegralSiteCoordinate(0, np.array([1, 2, 3]))

assert str(site) == "0, 1 2 3"

  • IntegralSiteCoordinate may be copied with IntegralSiteCoordinate.copy, copy.copy, or copy.deepcopy.
