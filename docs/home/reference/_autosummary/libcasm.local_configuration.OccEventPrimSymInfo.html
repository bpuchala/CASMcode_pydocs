OccEventPrimSymInfo#

Package: libcasm-configuration v3.0a1

class libcasm.local_configuration.OccEventPrimSymInfo(
prim: Prim,
system: OccSystem,
prototype_event: OccEvent,
phenomenal_clusters: list[Cluster] | None = None,
equivalent_generating_op_indices: list[int] | None = None,
)[source]#

Bases: object

Information about OccEvent that are equivalent with respect to a prim factor group

Parameters:

  • prim (Prim) – The prim.

  • system (OccSystem) – Occupation system, for index conversions.

  • prototype_event (OccEvent) – The prototype event. The underlying cluster prototype_event.cluster must be chosen from one of the equivalents that is generated by make_periodic_orbit() using the prim factor group.

  • phenomenal_clusters (Optional[list[Cluster]]) –

    The clusters at which the equivalent events are located. By default, the phenomenal clusters are generated from prototype_event and the prim factor group. May be provided to ensure consistency of (unitcell_index, equivalent_index) event positions with those used by a local clexulator.

    Note that these clusters are expected to be with the site order as transformed from the prototype cluster by the equivalents generating factor group operations, without sites being sorted after transformation.

  • equivalent_generating_op_indices (Optional[list[int]]) – The indices of prim factor group operations that generate the equivalent events from the prototype event, up to a translation. By default, the indices are generated from event and the prim factor group. May be provided to ensure consistency of (unitcell_index, equivalent_index) event positions with those used by a local clexulator.
